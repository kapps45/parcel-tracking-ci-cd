# 📦 Parcel Tracker

Консольный сервис на **Go** для регистрации и управления посылками с хранением данных в **SQLite**.

Проект демонстрирует работу с базой данных через `database/sql`, разделение логики хранения и бизнес-операций, автоматизированное тестирование, контейнеризацию и CI/CD.

## 🔧 Возможности

- 📦 Регистрация новых посылок
- 👤 Получение списка посылок клиента
- 🔄 Последовательное изменение статуса доставки
- 📍 Изменение адреса зарегистрированной посылки
- 🗑️ Удаление посылки до момента отправки
- 🗄️ Хранение данных в SQLite
- ⚙️ Автоматическое создание таблицы при запуске

## 📦 Статусы посылки

Жизненный цикл посылки состоит из трёх состояний:

`registered` → `sent` → `delivered`

Изменение адреса и удаление доступны только для посылок со статусом `registered`.

## 🗄️ Структура данных

В SQLite используется таблица `parcel`:

| Поле | Назначение |
|---|---|
| `number` | Уникальный номер посылки |
| `client` | Идентификатор клиента |
| `status` | Текущий статус доставки |
| `address` | Адрес доставки |
| `created_at` | Время регистрации |

## 🧪 Тестирование

Для проверки работы хранилища используются автоматизированные тесты.

Запуск всех тестов:

    go test ./...

Проверка кода с помощью `go vet`:

    go vet ./...

## 🐳 Docker

Проект поддерживает сборку и запуск в Docker-контейнере.

Сборка образа:

    docker build -t parcel-tracker .

Запуск контейнера:

    docker run --rm parcel-tracker

## ⚙️ CI/CD

GitHub Actions выполняет автоматическую проверку проекта:

- 🔍 Запуск `go vet`
- 🧪 Выполнение тестов
- 🐳 Сборка Docker-образа
- 📤 Публикация образа в Docker Hub при создании версии с тегом `v*`

Для публикации Docker-образа используются секреты GitHub Actions.
